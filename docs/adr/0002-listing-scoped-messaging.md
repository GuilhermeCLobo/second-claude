# Conversations are scoped to a Listing, not a general messaging system

A Conversation is always anchored to exactly one `(Listing, other User)` pair — there is no way for two Users to message each other outside the context of a specific Listing, and no general inbox/DM concept. We chose this over a general-purpose messaging system because the only stated need is "ask a question about a listing before buying"; a general DM system is a much larger surface (arbitrary-recipient threads, contact/blocking concerns, a different data model) that nothing in the product actually calls for. The trade-off is that Users can't continue a relationship (e.g. negotiate a second item) outside of starting a new conversation on another Listing — acceptable for a learning project's scope, but worth knowing before assuming general messaging "should just work" here.
